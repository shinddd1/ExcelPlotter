# 📊 Excel Plotter - 고급 데이터 시각화 도구

Excel 데이터를 전문적인 그래프로 변환하는 강력한 Python 애플리케이션입니다.

## ✨ 주요 기능

### 📈 **데이터 처리**
- **Excel 파일 지원**: `.xlsx`, `.xls` 파일 직접 로드
- **다중 시트 지원**: 여러 워크시트에서 데이터 선택
- **실시간 미리보기**: 데이터 로드 시 즉시 그래프 생성
- **자동 새로고침**: 데이터 변경 시 자동으로 그래프 업데이트

### 🎨 **고급 그래프 설정**
- **시간축 지원**: Timestamp 컬럼 자동 인식 및 시간축 설정
- **숫자축 설정**: X/Y축 간격을 단위값으로 설정 (제한 없음)
- **다양한 그래프 스타일**: SciencePlots 스타일 기본 적용
- **실시간 설정**: 더블클릭으로 설정 창 열기, 실시간 미리보기

### 🖼️ **이미지 저장 및 공유**
- **원클릭 저장**: 버튼 하나로 이미지 저장 + 클립보드 복사
- **자동 파일명**: `YYYYMMDD_HHMMSS_제목.png` 형식
- **고품질 출력**: 300 DPI 고해상도 이미지
- **클립보드 통합**: 저장과 동시에 클립보드에 복사

### 🎯 **사용자 친화적 인터페이스**
- **직관적 UI**: 한글 인터페이스로 쉬운 사용
- **실시간 미리보기**: 설정 변경 시 즉시 반영
- **키보드 단축키**: 효율적인 작업을 위한 단축키 지원
- **확대/축소**: 마우스 휠로 그래프 확대/축소

## 🚀 빠른 시작

### 📦 **실행 파일 사용 (권장)**
1. `dist/ExcelPlotter.exe` 파일을 다운로드
2. 더블클릭하여 실행
3. Python 설치 없이 바로 사용 가능

### 🐍 **소스 코드 실행**
```bash
# 저장소 클론
git clone <repository-url>
cd Plotting

# 의존성 설치
pip install -r requirements.txt

# 애플리케이션 실행
python app.py
```

## 📋 사용법

### 1️⃣ **데이터 로드**
- **파일 열기**: "파일 열기" 버튼으로 Excel 파일 선택
- **시트 선택**: 드롭다운에서 원하는 워크시트 선택
- **컬럼 선택**: X축과 Y축에 사용할 컬럼 선택

### 2️⃣ **그래프 설정**
- **더블클릭**: 그래프 영역을 더블클릭하여 설정 창 열기
- **시간축 설정**: Timestamp 컬럼 선택 시 자동으로 시간축 모드
- **숫자축 설정**: 일반 숫자 컬럼 선택 시 숫자축 모드
- **간격 설정**: X/Y축 간격을 원하는 단위값으로 설정

### 3️⃣ **이미지 저장**
- **저장 버튼**: "이미지 저장" 버튼 클릭
- **자동 저장**: `Plot Image` 폴더에 자동 저장
- **클립보드 복사**: 동시에 클립보드에도 복사됨

## ⚙️ 고급 설정

### 🎨 **그래프 스타일**
- **기본 스타일**: SciencePlots + No LaTeX
- **폰트 크기**: 제목(14), 축 레이블(16), 축 숫자(12)
- **색상 테마**: 전문적인 색상 팔레트

### 📊 **축 설정**
- **시간축**: 
  - 형식: `시:분:초:밀리초`, `시:분:초`, `시:분` 등
  - 범위: 시작/종료 시간 설정
- **숫자축**:
  - 간격: 원하는 단위값으로 설정 (제한 없음)
  - 범위: 최소/최대값 설정

### 🖼️ **이미지 설정**
- **해상도**: 300 DPI 고품질
- **형식**: PNG (투명 배경 지원)
- **파일명**: 자동 생성 (`YYYYMMDD_HHMMSS_제목.png`)

## 🐛 문제 해결

### **자주 묻는 질문**

**Q: Excel 파일이 열리지 않아요**
A: 파일이 다른 프로그램에서 열려있지 않은지 확인하고, 파일 형식이 `.xlsx` 또는 `.xls`인지 확인하세요.

**Q: 그래프가 표시되지 않아요**
A: X축과 Y축 컬럼이 올바르게 선택되었는지 확인하고, 데이터에 유효한 숫자 값이 있는지 확인하세요.

**Q: 이미지 저장이 안 돼요**
A: `Plot Image` 폴더에 쓰기 권한이 있는지 확인하고, 디스크 공간이 충분한지 확인하세요.

**Q: 프로그램이 느려요**
A: 대용량 데이터의 경우 처리 시간이 오래 걸릴 수 있습니다. 데이터 크기를 줄이거나 메모리를 늘려보세요.
