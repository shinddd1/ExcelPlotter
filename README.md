# Excel Plotter (SciencePlots) 📊

Excel 데이터를 SciencePlots 스타일로 시각화하는 고급 데스크톱 애플리케이션입니다.

## ✨ 주요 기능

### 📁 데이터 로딩
- **Excel 통합**: xlwings를 통한 실시간 Excel 연동
- **자동 새로고침**: Excel 데이터 변경 시 자동 업데이트
- **다중 시트 지원**: 여러 워크시트에서 데이터 선택
- **파일 형식**: .xlsx, .xls, .csv 지원

### 🎨 고급 플롯팅 기능
- **SciencePlots 스타일**: 과학 논문 수준의 고품질 그래프
- **다중 Y축**: 여러 컬럼을 동시에 시각화
- **실시간 미리보기**: 설정 변경 시 즉시 반영
- **줌 기능**: 드래그로 영역 확대/축소, 단계별 줌 아웃
- **플롯 저장**: PNG, SVG, PDF 형식으로 고해상도 저장

### 🎛️ 고급 스타일링
- **Y축 컬럼별 개별 설정**:
  - 색상 선택 (색상 선택기 + 미리보기)
  - 선 굵기 (0.5~10.0)
  - 선 스타일 (실선, 점선, 점쇄선, 점선)
  - 마커 스타일 (원, 사각형, 삼각형, 다이아몬드 등)
  - 마커 크기 (1~50)
  - 플롯 타입 (선만, 점만, 선+점)

### ⏰ 시간축 지원
- **자동 시간 인식**: Timestamp 컬럼 자동 감지
- **시간 범위 설정**: 시작/종료 시간 수동 설정
- **시간 간격 조절**: 초/분/시간/일 단위로 틱 간격 설정
- **시간 형식**: HH:MM:SS.XXX 형식으로 표시

### 📐 축 설정
- **숫자축/시간축 탭**: 데이터 타입에 따른 자동 탭 전환
- **축 범위**: 자동/수동 범위 설정
- **틱 수 조절**: X/Y축 틱 개수 설정
- **폰트 크기**: 제목, 라벨, 틱 폰트 크기 조절

## 🚀 설치 및 실행

### 요구 사항
- Python 3.9+
- Windows (xlwings 지원)
- Microsoft Excel (Excel 통합 기능 사용 시)

### 설치
1. **가상환경 생성** (권장)
```bash
python -m venv .venv
.venv\Scripts\activate
```

2. **의존성 설치**
```bash
pip install -r requirements.txt
```

### 실행
```bash
python app.py
```

## 📖 사용법

### 1. Excel 연결
1. "Excel 연결" 버튼 클릭
2. Excel 파일이 자동으로 로드됨
3. 시트와 컬럼이 자동으로 감지됨

### 2. 데이터 선택
1. **X축 컬럼**: 드롭다운에서 선택
2. **Y축 컬럼**: 리스트박스에서 다중 선택 (Ctrl+클릭)

### 3. 플롯 생성
1. "플롯" 버튼 클릭하여 기본 그래프 생성
2. 그래프를 더블클릭하여 고급 설정 창 열기

### 4. 고급 설정
1. **플롯 스타일**: Y축 컬럼별 개별 스타일 설정
2. **축 설정**: 
   - 숫자축: 범위, 틱 수, 폰트 크기
   - 시간축: 시간 범위, 간격, 형식
3. **실시간 미리보기**: 설정 변경 시 즉시 반영

### 5. 줌 기능
1. "🔍 줌 모드" 버튼 클릭
2. 그래프에서 드래그하여 영역 선택
3. "줌 아웃" 버튼으로 이전 단계로 복원
4. "줌 리셋" 버튼으로 원본 상태로 복원

### 6. 저장
1. "저장" 버튼 클릭
2. 파일 형식 선택 (PNG/SVG/PDF)
3. 고해상도 (300 DPI)로 저장
